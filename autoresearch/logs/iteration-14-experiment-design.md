# 迭代 14: 组合实验设计 — 自我进化机制对比验证

## 14.1 实验假设

基于 Wave 1 的研究发现，我们提出三个可检验假设：

### H1: 外部反馈 > 内部反馈
**假设**: 使用外部验证信号（测试执行结果）的反思机制，优于纯自我批评（无外部信号）。

**依据**: CRITIC 论文证明外部工具反馈至关重要；报告中的"反思质量受限"瓶颈分析。

**预期**: Reflexion（外部反馈）> Self-Refine（内部反馈）> Direct（无反馈）

### H2: 跨任务洞察可迁移
**假设**: 从任务中提取的抽象洞察可以提升后续任务的首次尝试成功率（ExpeL 机制）。

**依据**: ExpeL 论文显示随经验积累性能持续提升。

**预期**: 带洞察积累的策略，后半段任务的首尝试成功率 > 前半段

### H3: 组合策略优于单一策略
**假设**: Reflexion（反思记忆）+ ExpeL（洞察提取）+ Best-of-N（采样）的组合，在所有指标上优于任何单一策略。

**依据**: GEPA 证明了反思+进化的组合威力；报告结论"组合优于单一"。

**预期**: Combined > max(Reflexion, Best-of-N) 的成功率，且成本可接受

## 14.2 实验设计

### 策略矩阵

| 策略 | 外部反馈 | 反思记忆 | 跨任务洞察 | 采样 |
|------|----------|----------|------------|------|
| **Direct** | ✗ | ✗ | ✗ | 1 |
| **Best-of-N** | ✓（选择用）| ✗ | ✗ | N=5 |
| **Self-Refine** | ✗（内部）| 轮内 | ✗ | 1 |
| **Reflexion** | ✓ | ✓ | ✗ | 1 |
| **Combined** | ✓ | ✓ | ✓ | 轮内 2 |

### 任务套件（8 个代码生成任务）

| 任务 | 难度 | 失败模式数 | 关键能力 |
|------|------|-----------|----------|
| safe_divide | 低 | 2 | 边界条件 |
| is_palindrome | 低 | 2 | 字符串处理 |
| parse_duration | 中 | 3 | 正则解析 |
| merge_intervals | 中 | 3 | 排序+合并逻辑 |
| fib | 低 | 2 | 迭代+边界 |
| word_freq | 中 | 3 | 排序规则 |
| flatten | 中 | 2 | 递归 |
| chunk_list | 低 | 2 | 边界+剩余处理 |

每个任务有：
- 自然语言描述（给模型的输入）
- 正确解答（mock 的"成功生成"）
- 2-3 个 buggy 变体（每个有独特失败签名）
- 真实单元测试（子进程真实执行验证）

### 测量指标

1. **任务成功率** — 在预算内最终通过测试的任务比例
2. **首次尝试成功率** — 第一次生成就通过的比例（衡量直觉能力）
3. **平均尝试次数** — 成功任务的效率
4. **总 LLM 调用数** — 成本代理指标
5. **学习曲线** — 前半段任务 vs 后半段任务的首次成功率差值（衡量洞察迁移）

### 实验控制

- **固定任务顺序** — 所有策略按相同顺序执行任务
- **确定性随机** — mock 后端用 `(seed, task_id, attempt)` 派生 RNG，完全可复现
- **相同预算** — 所有策略共享相同的尝试预算（max_attempts=5）
- **真实验证** — 测试在独立子进程中真实执行，非模拟

### 重要声明：关于 Mock 后端

由于本机无 API key，实验默认使用 **MockBackend**：
- 它模拟一个"有固定能力水平（base_p≈0.35）的模型"
- 失败时从任务的 buggy 变体池中采样（模拟真实模型的典型错误）
- 反思文本会消除对应的失败模式（模拟 Reflexion 的记忆机制）
- 洞察提升后续任务的 base_p（模拟 ExpeL 的迁移效应）

**它验证的是**: 框架机制是否正确、策略差异是否符合理论预期。
**它不验证的是**: 真实 LLM 的具体行为。接真实后端只需 `--backend openai` + API key。

## 14.3 预期结果（基于论文证据的预测）

| 策略 | 预测成功率 | 预测调用数 | 依据 |
|------|-----------|-----------|------|
| Direct | ~35% | 8 | base_p |
| Best-of-N | ~85% | 40 | 1-(1-p)^5 |
| Self-Refine | ~55% | 16-24 | 部分自我纠错 |
| Reflexion | ~90% | 20-30 | 失败模式消除 |
| Combined | ~95%+ | 25-35 | 反思+洞察+采样 |

**关键预测**: Combined 的首次成功率会随任务推进上升（洞察迁移），而 Reflexion 持平。

## 14.4 原型实现

已在 `experiments/` 目录实现可运行原型：

```
experiments/
├── README.md                 — 实验协议与使用说明
├── run_experiment.py         — CLI 入口
├── evolve_lab/
│   ├── __init__.py
│   ├── tasks.py              — 8 任务套件（描述/正确解/buggy变体/测试）
│   ├── backends.py           — MockBackend + OpenAIBackend
│   ├── strategies.py         — 5 种策略实现
│   └── runner.py             — 实验编排 + 指标收集
└── results/                  — 结果输出（JSON + 摘要）
```

### 运行方式

```bash
# Mock 后端（离线可跑）
python experiments/run_experiment.py

# 真实后端（需要 API key）
export OPENAI_API_KEY=sk-...
export OPENAI_BASE_URL=https://api.deepseek.com/v1  # 可选，兼容任何 OpenAI 格式端点
python experiments/run_experiment.py --backend openai --model deepseek-chat
```
