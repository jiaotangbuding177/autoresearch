# 迭代 6: Self-Reflection / Reflexion 调研

## 自我进化机制概述
Agent 自我进化的核心思路：**通过反思和迭代改进，而非权重更新**。这是 LLM Agent 与传统 RL Agent 的根本区别。

---

## 6.1 Reflexion：语言化自我反思

### 基本信息
- **论文**: Reflexion: Language Agents with Verbal Reinforcement Learning
- **arXiv ID**: 2303.11366
- **核心创新**: 通过语言反馈而非权重更新来强化 Agent

### 工作原理

#### 反思循环（Reflection Loop）
```
任务执行 → 反馈信号 → 语言化反思 → 存储到情景记忆 → 下次执行时参考
    ↑                                                        ↓
    └────────────────── 迭代改进 ──────────────────────────────┘
```

#### 关键机制
1. **任务执行** — Agent 尝试完成任务
2. **反馈接收** — 可以是标量值（成功/失败）或自由文本
3. **语言化反思** — Agent 用自然语言分析失败原因
4. **情景记忆** — 反思结果存储到记忆缓冲区
5. **未来参考** — 后续任务执行时查询历史反思

### 反馈信号类型
- **外部反馈** — 环境返回的成功/失败信号
- **内部模拟** — Agent 自己评估执行质量
- **标量值** — 数值化的奖励信号
- **自由文本** — 详细的错误描述

### 关键结果

| 基准 | Reflexion | 基线 | 提升 |
|------|-----------|------|------|
| HumanEval（代码） | **91%** pass@1 | GPT-4: 80% | +11% |
| 序列决策 | 显著提升 | — | — |
| 语言推理 | 显著提升 | — | — |

### 核心优势
1. **无需训练** — 不需要梯度更新或微调
2. **低成本** — 只需存储和查询文本反思
3. **灵活** — 可以整合多种反馈源
4. **可解释** — 反思过程是人类可读的

### 局限性
1. **记忆容量有限** — 长文本反思占用大量上下文窗口
2. **反思质量依赖模型能力** — 弱模型的反思可能不准确
3. **无法积累长期知识** — 每次任务独立，无法跨任务迁移
4. **可能陷入局部最优** — 相似的失败模式导致相似的反思

## 6.2 Self-Refine：迭代自我优化

### 基本信息
- **论文**: Self-Refine: Iterative Refinement with Self-Feedback
- **arXiv ID**: 2303.17651
- **核心创新**: 单个 LLM 扮演三个角色进行迭代优化

### 三角色循环

```
┌─────────────┐
│  Generator  │ ← 生成初始输出
└──────┬──────┘
       ↓
┌─────────────────┐
│ Feedback Provider │ ← 自我反馈
└──────┬──────────┘
       ↓
┌─────────────┐
│   Refiner   │ ← 根据反馈修改
└──────┬──────┘
       ↓
   （重复直到满意）
```

### 关键创新
1. **无需额外训练** — 完全在推理时进行
2. **单模型完成** — 不需要多个模型或外部反馈
3. **人类启发** — 模拟人类修改自己文本的过程

### 评测结果
- **7 个任务** — 包括数学推理、对话生成等
- **模型** — GPT-3.5、ChatGPT、GPT-4
- **平均提升** — **~20%** 绝对提升
- **人类偏好** — Self-Refine 输出被人类和自动指标共同偏好

### 与 Reflexion 的对比

| 维度 | Reflexion | Self-Refine |
|------|-----------|-------------|
| **反馈来源** | 环境 + 自我 | 纯自我 |
| **记忆机制** | 情景记忆（跨任务） | 无记忆（单任务内） |
| **迭代粒度** | 跨多次任务尝试 | 单次任务内多次迭代 |
| **适用场景** | 可重试的任务 | 任何生成任务 |
| **核心机制** | 语言化反思 | 自我反馈+修改 |

## 6.3 自我反思方法分类学

```
Agent 自我进化机制
│
├── 单任务内迭代
│   ├── Self-Refine — 生成→反馈→修改循环
│   ├── CRITIC — 工具增强的自我批评
│   └── Chain-of-Verification — 自问自答验证
│
├── 跨任务学习
│   ├── Reflexion — 情景记忆 + 语言反思
│   ├── ExpeL — 经验学习（Experience Learning）
│   └── LATS — 语言 Agent 树搜索
│
└── 混合方法
    ├── Self-Play — 自我对弈
    └── Evolutionary Agent — 进化算法 + Agent
```

## 6.4 核心启示

### 1. 语言作为学习媒介
传统 RL 通过权重更新学习，LLM Agent 通过**语言化反思**学习。这是 LLM 的独特优势。

### 2. 无需梯度更新
自我反思方法在推理时就能改进，大幅降低了"学习"的成本。

### 3. 可解释性
反思过程是自然语言，人类可以理解 Agent 为什么失败、如何改进。

### 4. 局限性
- **上下文窗口瓶颈** — 大量反思文本消耗有限的上下文
- **反思质量** — 模型能力上限决定了反思质量上限
- **无法真正"学习"** — 只是临时策略，模型本身没有改变
